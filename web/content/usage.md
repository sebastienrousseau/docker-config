# Usage

`@sebastienrousseau/docker-config` can be consumed across all standard module formats.

## CommonJS

```javascript
module.exports = require("@sebastienrousseau/docker-config");
```

## ES Modules

```javascript
import config from "@sebastienrousseau/docker-config";
export default config;
```

## In `package.json`

```json
{
  "docker": "@sebastienrousseau/docker-config"
}
```
